Matching Piecewise Limits & Continuity

Find unknown constants (c or d) to make functions continuous

Step-Through Lesson: Finding Unknown Constants

To make a piecewise function continuous at a transition point, the limit from the left must equal the limit from the right (and equal the function value at that point).

Example Problem: Find the value of c such that f(x) is continuous everywhere:

{
cx2 - 3,    x < 2 cx + 2,      x ≥ 2

Step 1: Transition Point
The rule changes at x = 2. For f(x) to be continuous, the expression from the left side evaluated at x = 2 must equal the expression from the right side evaluated at x = 2.

Step 2: Equate Expressions at x = 2
Substitute x = 2 into both pieces and set them equal:
c(2)2 - 3 = c(2) + 2
4c - 3 = 2c + 2

Step 3: Algebraic Isolation
Subtract 2c from both sides:
2c - 3 = 2
Add 3 to both sides:
2c = 5
Divide by 2:
5 2


Final Answer: c = 5 / 2

Practice Question 1

Find the value of c that makes the function continuous:

{
cx + 5,    x ≤ 3 x2 - c,    x > 3

Solution:
Mathematical Steps Explanation
c(3) + 5 = (3)2 - c Set left and right expressions equal at the transition point x = 3
3c + 5 = 9 - c Simplify terms on both sides
4c + 5 = 9 Add c to both sides
4c = 4 Subtract 5 from both sides
c = 1 Divide by 4

Final Answer: c = 1

Mathematical Steps Explanation

4 3
