Understanding \(\delta\) (Delta)

Find the largest \(\delta\) such that if \(|x - 4| < \delta\), then \(|\sqrt{x} - 2| < 0.4\).

Target Output Window:
We want \(\sqrt{x}\) to be within \(0.4\) of \(2\).
\(2 - 0.4 = 1.6\) and \(2 + 0.4 = 2.4\)

Target Input Window:
Solving \(\sqrt{x} = 1.6\) gives \(x = 2.56\)
Solving \(\sqrt{x} = 2.4\) gives \(x = 5.76\)
Status: Safe
Current Calculation:
Distance to right boundary: \(5.76 - 4 = 1.76\)
Distance to left boundary: \(4 - 2.56 = 1.44\)

To stay inside both boundaries, \(\delta\) must be \(\le 1.44\).
