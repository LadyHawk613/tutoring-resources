Walkthrough Demonstration: Factoring & Direct Substitution

Evaluate the limit:

limx → -1
x2 - 1 x + 1

Step 1: Indeterminate Form Check
Plugging in x = -1 gives:
(-1)2 - 1 -1 + 1
=
0 0

Since we get zero over zero, the form is indeterminate. We must factor the numerator.
Step 2: Algebra & Cancellation
Factor the numerator as a difference of squares: x2 - 1 = (x - 1)(x + 1).
Cancel the common term (x + 1) from numerator and denominator:
(x - 1)(x + 1) x + 1
= x - 1

Step 3: Direct Substitution of Simplified Form
Evaluate the limit of the simplified expression as x approaches -1:
limx → -1
(x - 1) = -1 - 1 = -2

Practice Questions (Worksheet Scenarios 1 - 9)

1. Difference of Squares

Evaluate:

limx → 2
4 - x2 x - 2

Solution:
1. Direct substitution yields zero over zero.
2. Factor numerator: 4 - x2 = (2 - x)(2 + x) = -(x - 2)(x + 2).
3. Cancel (x - 2) to leave -(x + 2).
4. Substitute x = 2: -(2 + 2) = -4

2. Trinomial Denominator Factoring

Evaluate:

limx → 1
x - 1 x2 + 2x - 3

Solution:
1. Factor denominator: x2 + 2x - 3 = (x - 1)(x + 3).
2. Cancel (x - 1) to get 1 / (x + 3).
3. Substitute x = 1: 1/4

3. Linear Denominator Factoring

Evaluate:

limx → -2
x + 2 x2 + 5x + 6

Solution:
1. Factor denominator: x2 + 5x + 6 = (x + 2)(x + 3).
2. Cancel (x + 2) to get 1 / (x + 3).
3. Substitute x = -2: 1 / (-2 + 3) = 1

4. Rationalizing Radicals

Evaluate:

limx → 0
√x + 5 - √5 x

Solution:
1. Multiply by the conjugate: √x + 5 + √5.
2. Simplify numerator: (x + 5) - 5 = x.
3. Cancel x and substitute x = 0: 1 / (2√(5))

5. Rationalizing Radicals (Negative Shift)

Evaluate:

limx → -3
√1 - x - 2 x + 3

Solution:
1. Multiply by conjugate √1 - x + 2.
2. Simplify numerator: (1 - x) - 4 = -(x + 3).
3. Cancel (x + 3) and substitute x = -3: -1/4

6. Nested Fraction Combination

Evaluate:

limx → -4
xx + 2
- 2 x + 4

Solution:
1. Combine numerator terms over common denominator (x + 2) to get -(x + 4) / (x + 2).
2. Divide by (x + 4) to leave -1 / (x + 2).
3. Substitute x = -4: 1/2
