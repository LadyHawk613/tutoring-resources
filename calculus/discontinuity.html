Classifying Discontinuities

Interactive Lesson Walkthrough & Non-Sequential Practice Hub

Type 1: Removable (Point) Discontinuity

Definition: The limit limx→a f(x) exists, but either f(a) is undefined or limx→a f(x) ≠ f(a) (the graph has a single missing or displaced point).

Walkthrough Example

Function:

f(x) = {
x² + 1 if x < 1
1 if x = 1
x + 1 if x > 1

at point of interest x = 1

Step 1: One-Sided Limits
• Left-hand limit (x → 1⁻):
limx→1⁻
(x² + 1) = (1)² + 1 = 2

• Right-hand limit (x → 1⁺):
limx→1⁺
(x + 1) = 1 + 1 = 2

Step 2: Conclusion
Since the left-hand limit (2) equals the right-hand limit (2), the overall limit exists: limx→1 f(x) = 2.
However, the function value is f(1) = 1. Because limx→1 f(x) ≠ f(1), this is a Removable (Point) Discontinuity!

Visual representation showing the hole at (1, 2) and the displaced point at (1, 1).

Type 2: Jump Discontinuity

Definition: The left-hand limit and right-hand limit both exist and are finite, but they are not equal (limx→a⁻ f(x) ≠ limx→a⁺ f(x)).

Walkthrough Example

Function:

f(x) = {
x³ if x < 1
3 - x if x ≥ 1

at point of interest x = 1

Step 1: One-Sided Limits
• Left-hand limit (x → 1⁻):
limx→1⁻
(x³) = (1)³ = 1

• Right-hand limit (x → 1⁺):
limx→1⁺
(3 - x) = 3 - 1 = 2

Step 2: Conclusion
The left-hand limit is 1 and the right-hand limit is 2. Since 1 ≠ 2, the two-sided limit does not exist due to a finite break.
Because both one-sided limits are finite but unequal, this is a Jump Discontinuity!

Type 3: Infinite Discontinuity

Definition: At least one of the one-sided limits approaches infinity (∞ or -∞), creating a vertical asymptote.

Walkthrough Example

Function:
f(x) =

3 (x - 4)²
at point of interest x = 4

Step 1: Analyze Asymptotic Behavior
As x → 4, the denominator (x - 4)² approaches 0 through strictly positive numbers.
• Limit expression:
limx→4
3 (x - 4)²
= ∞

Step 2: Conclusion
Because the limit grows without bound toward infinity, this represents an Infinite Discontinuity with a vertical asymptote at x = 4.

Discontinuity Classification Summary

Quick reference guide for analyzing any point x = a:

Type Key Condition Visual Characteristic
Removable limx→a f(x) exists, but ≠ f(a) (or f(a) undefined) A single hole or missing point in the graph.
Jump One-sided limits exist and are finite, but limx→a⁻ f(x) ≠ limx→a⁺ f(x) A finite break/step between two distinct horizontal levels.
Infinite At least one one-sided limit approaches ∞ or -∞ A vertical asymptote where graph shoots upward/downward.
