Graphing Functions

Parent functions · Transformations · Examples — graphs are plotted live from the real equations

Linear

Parentf(x) = x
Generalf(x) = m(x − h) + k

Parameter Effects

  • m > 0 rises left to right; m < 0 falls left to right
  • |m| > 1 steeper slope; 0 < |m| < 1 shallower slope
  • h shifts the line horizontally (reference point)
  • k shifts the line vertically
  • Line passes through (h, k)
  • Domain: all real numbers
  • Range: all real numbers (unless m = 0)

Absolute Value

Parentf(x) = |x|
Generalf(x) = a|x − h| + k

Parameter Effects

  • a > 0 opens upward; a < 0 opens downward
  • |a| > 1 narrows; 0 < |a| < 1 widens
  • h shifts the vertex horizontally (right if positive)
  • k shifts the vertex vertically (up if positive)
  • Vertex is at (h, k)
  • Domain: all real numbers
  • Range: [k, ∞) if a > 0; (−∞, k] if a < 0

Quadratic

Parentf(x) = x²
Generalf(x) = a(x − h)² + k

Parameter Effects

  • a > 0 opens upward (∪); a < 0 opens downward (∩)
  • |a| > 1 narrows the parabola; 0 < |a| < 1 widens it
  • h shifts the vertex horizontally
  • k shifts the vertex vertically
  • Vertex: (h, k) — maximum or minimum
  • Axis of symmetry: x = h
  • Domain: all real numbers
  • Range: [k, ∞) if a > 0; (−∞, k] if a < 0

Cubic

Parentf(x) = x³
Generalf(x) = a(x − h)³ + k

Parameter Effects

  • a > 0 rises left to right; a < 0 reflects (falls left to right)
  • |a| > 1 stretches (steeper); 0 < |a| < 1 compresses (flatter)
  • h shifts the inflection point horizontally
  • k shifts the inflection point vertically
  • Inflection point: (h, k) — graph flattens briefly here
  • Domain: all real numbers
  • Range: all real numbers

Square Root

Parentf(x) = √x
Generalf(x) = a√(x − h) + k

Parameter Effects

  • a > 0 curves upward; a < 0 reflects over x-axis
  • |a| > 1 stretches vertically; 0 < |a| < 1 compresses
  • h shifts the starting point horizontally
  • k shifts the starting point vertically
  • Starting point (endpoint): (h, k)
  • Domain: x ≥ h (requires x − h ≥ 0)
  • Range: [k, ∞) if a > 0; (−∞, k] if a < 0

Exponential

Parentf(x) = bˣ (b > 0, b ≠ 1)
Generalf(x) = a · b^(x−h) + k

Parameter Effects

  • b > 1 → exponential growth (rises right)
  • 0 < b < 1 → exponential decay (falls right)
  • a > 0 same side as parent; a < 0 reflects over asymptote
  • h shifts the graph horizontally
  • k sets the horizontal asymptote y = k
  • Domain: all real numbers
  • Range: (k, ∞) if a > 0; (−∞, k) if a < 0

Example 1
f(x) = 2^(x−1) + 3
1a = 1, b = 2, h = 1, k = 3
2Asymptote: y = 3
3Key point: (1, 4) since 2⁰ + 3 = 4
4Growth; Domain all reals; Range (3, ∞)

2Asymptote: y = −2 (decay toward it)

4Decay; Domain all reals; Range (−2, ∞)

Logarithmic

Parentf(x) = logb(x) (b > 0, b ≠ 1)
Generalf(x) = a · logb(x−h) + k

Parameter Effects

  • b > 1 → increasing, rises slowly to the right
  • a > 0 same orientation; a < 0 reflects over the asymptote
  • h shifts the vertical asymptote and graph horizontally
  • k shifts the graph vertically
  • Vertical asymptote: x = h
  • Domain: x > h
  • Range: all real numbers

Rational (Even)

Parentf(x) = 1x²
Generalf(x) = a(x−h)² + k

Parameter Effects

  • a > 0 branches open above the horizontal asymptote; a < 0 open below
  • |a| > 1 branches pull away faster; 0 < |a| < 1 stay closer to the asymptotes
  • h shifts the vertical asymptote (x = h)
  • k shifts the horizontal asymptote (y = k)
  • Vertical asymptote: x = h · Horizontal asymptote: y = k
  • Even function — symmetric about the line x = h
  • Domain: x ≠ h
  • Range: (k, ∞) if a > 0; (−∞, k) if a < 0

Rational (Odd)

Parentf(x) = 1x
Generalf(x) = a(x−h) + k

Parameter Effects

  • a > 0 branches sit upper-right / lower-left of the asymptotes; a < 0 flips them
  • |a| > 1 branches pull farther from the asymptotes; 0 < |a| < 1 stay closer
  • h shifts the vertical asymptote (x = h)
  • k shifts the horizontal asymptote (y = k)
  • Vertical asymptote: x = h · Horizontal asymptote: y = k
  • Odd function — symmetric about the point (h, k)
  • Domain: x ≠ h
  • Range: y ≠ k
