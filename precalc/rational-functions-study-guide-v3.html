Rational Functions Master Guide

Comprehensive Study Notes & 10 Practice Problems

Step 0: The Golden Rule

Before analyzing any rational function of the general form, you must completely factor both the numerator and the denominator first.

$$f(x) = \frac{P(x)}{Q(x)}$$

Core Features Cheat Sheet

1. Domain

Includes all real numbers except those that make the original denominator equal to zero.

2. Holes (Removable Discontinuities)

Occur when a factor cancels out from both the numerator and denominator. Find the x-coordinate by setting the cancelled factor to zero, then plug it into the simplified function to find y.

3. Vertical Asymptotes

Occur where the denominator equals zero for factors that do not cancel out. Written as equations like \(x = c\).

4. X-Intercepts

Points where the graph crosses the x-axis. Set the numerator of the simplified function equal to zero and solve for x.

5. Y-Intercept

Evaluate the function at zero: \(f(0)\).

6. Horizontal Asymptotes

Compare degrees of numerator (\(n\)) and denominator (\(m\)):

  • If \(n < m\): Horizontal asymptote at \(y = 0\).
  • If \(n = m\): Horizontal asymptote at \(y = \frac{a}{b}\) (ratio of leading coefficients).
  • If \(n > m\): No horizontal asymptote (check for slant asymptote).

Practice Problems

Problem 1: Vertical Asymptotes

Find the vertical asymptote(s) of:

$$f(x) = \frac{(x - 9)(x + 2)}{(x + 2)(x + 4)}$$

Solution: The factor \((x + 2)\) cancels out, creating a hole at \(x = -2\). The remaining factor in the denominator is \((x + 4)\). Setting it to zero gives:

$$x = -4$$

Problem 2: Domain Calculation

Find the domain of the function:

$$g(x) = \frac{x^2 - 16}{x^2 + x - 12}$$

Solution: Factor the denominator into \((x + 4)(x - 3) = 0\). Restrictions are \(x = -4\) and \(x = 3\).
Interval Notation: \((-\infty, -4) \cup (-4, 3) \cup (3, \infty)\)

Problem 3: Word Problem Application

The cost of renting an AirBnB is $74 per guest plus a cleaning fee of $130. Write the cost per guest function \(C(x)\) and find how many guests are needed so each pays $100.

Solution:
1. Equation:

$$C(x) = \frac{74x + 130}{x}$$

2. Set equal to 100 and solve:

$$\frac{74x + 130}{x} = 100 \implies 74x + 130 = 100x \implies x = 5 \text{ guests}$$

Problem 4: Finding Holes

Find the coordinates of any hole(s) for the function:

$$h(x) = \frac{x^2 - x - 2}{x - 2}$$

Solution: Factor the numerator as \((x - 2)(x + 1)\). The factor \((x - 2)\) cancels out. Setting \(x - 2 = 0\) gives \(x = 2\). Plugging into the reduced function \(y = x + 1\) gives \(y = 3\).

$$\text{Hole at } (2, 3)$$

Problem 5: X-Intercepts

Find the x-intercept(s) of the function:

$$f(x) = \frac{x^2 - 9}{x^2 + 5x + 6}$$

Solution: Factor numerator to \((x-3)(x+3)\) and denominator to \((x+2)(x+3)\). The factor \((x+3)\) cancels, leaving simplified numerator \((x-3)\). Set numerator to zero:

$$x = 3 \quad (\text{Point: } (3, 0))$$

Problem 6: Y-Intercept

Find the y-intercept of the function:

$$f(x) = \frac{3x - 12}{x^2 + 2x + 4}$$

Solution: Evaluate \(f(0)\) by substituting \(0\) for all \(x\):

$$f(0) = \frac{3(0) - 12}{(0)^2 + 2(0) + 4} = \frac{-12}{4} = -3 \quad (\text{Point: } (0, -3))$$

Problem 7: Horizontal Asymptote (Equal Degrees)

Determine the horizontal asymptote of:

$$f(x) = \frac{5x^2 - 8x + 1}{2x^2 + 3}$$

Solution: The degree of the numerator equals the degree of the denominator (\(n = 2, m = 2\)). Take the ratio of the leading coefficients:

$$y = \frac{5}{2}$$

Problem 8: Horizontal Asymptote (Bottom Heavy)

Determine the horizontal asymptote of:

$$f(x) = \frac{4x + 7}{x^3 - 2x + 1}$$

Solution: The degree of the numerator is less than the denominator (\(n = 1, m = 3\)). Since it is bottom heavy:

$$y = 0$$

Problem 9: Complete Analysis

Find all vertical asymptotes and holes for:

$$f(x) = \frac{x(x - 5)}{(x - 5)(x + 3)}$$

Solution:
- Hole: Factor \((x - 5)\) cancels out, giving a hole at \(x = 5\).
- Vertical Asymptote: Remaining factor in the denominator is \((x + 3)\):

$$x = -3$$

Problem 10: Average Cost Application

A company produces custom skateboards. The fixed startup cost is $1,200 and each skateboard costs $45 to manufacture. Write the average cost function \(A(x)\) to produce \(x\) skateboards, and find the average cost if 100 skateboards are made.

Solution:
1. Equation:

$$A(x) = \frac{45x + 1200}{x}$$

2. Substitute \(x = 100\):

$$A(100) = \frac{45(100) + 1200}{100} = \frac{5700}{100} = \$57 \text{ per skateboard}$$
